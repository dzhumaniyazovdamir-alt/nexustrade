# Product scope

## Назначение

NexusTrade объединяет организации-покупателей, поставщиков, склады и перевозчиков. Система должна позволить управлять каталогом, ценами, закупками, продажами, резервами, отгрузками, возвратами и финансовыми документами в пределах одной организации.

## Пользователи

- владелец и администратор организации;
- менеджеры закупок и продаж;
- кладовщик и логист;
- бухгалтер и аналитик;
- внешний клиент.

## Границы первой версии

Первая продуктовая версия включает tenant-aware identity/RBAC, каталог и цены, складской учёт, закупки, заказы, отгрузки, возвраты, уведомления и операционную аналитику.

Не входят: реальный эквайринг и хранение карточных данных, бухгалтерская отчётность для регуляторов, оптимизация маршрутов и публичный marketplace.

## Нефункциональные требования

- строгая изоляция данных организаций;
- идемпотентность команд и обработчиков событий;
- отсутствие отрицательного доступного остатка при конкурентных заказах;
- аудит чувствительных действий;
- горизонтально масштабируемые stateless API и workers;
- диагностируемость через structured logs, metrics и traces;
- миграции схемы без `synchronize`;
- доступный интерфейс и поддержка клавиатурной навигации.

## Метрики успеха учебного проекта

- ключевые архитектурные решения объяснимы и подтверждены тестами;
- критические транзакционные сценарии воспроизводятся нагрузочными тестами;
- один bounded context выделен из монолита без изменения публичного поведения;
- для критических запросов сохранены планы выполнения до и после оптимизации.
