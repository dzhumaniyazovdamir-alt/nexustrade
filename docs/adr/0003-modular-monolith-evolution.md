# ADR-0003: Модульный монолит с эволюцией к сервисам

- Статус: accepted
- Дата: 2026-09-24

## Контекст

Микросервисы с первого дня усложнят транзакции, локальную разработку и диагностику до появления реальных требований к независимому масштабированию.

## Решение

Начать с модульного монолита с bounded contexts и явными портами. Межмодульное взаимодействие выполняется через публичный application API и domain/integration events. Первым кандидатом на выделение станет Notifications или Analytics после появления измеримой причины.

## Последствия

- быстрые изменения и локальные транзакции на раннем этапе;
- границы модулей нужно контролировать архитектурными правилами;
- outbox и версионированные контракты подготавливают безопасное выделение;
- сетевое разделение не применяется без необходимости.
