# ADR-0001: Nx и pnpm monorepo

- Статус: accepted
- Дата: 2026-09-24

## Контекст

API, Web, будущие workers и общие контракты должны развиваться согласованно, но сохранять явные границы.

## Решение

Использовать integrated Nx workspace и pnpm workspaces. Nx отвечает за project graph, кэширование задач и module-boundary rules; pnpm — за воспроизводимую и экономную установку зависимостей.

## Последствия

- единые команды lint/test/build и affected-проверки;
- видимые зависимости между проектами;
- дополнительная конфигурация Nx и необходимость синхронно обновлять плагины;
- общая библиотека не должна превращаться в хранилище бизнес-логики разных контекстов.
